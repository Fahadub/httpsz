Configuring Atlas

Atlas reads its configuration from atlas.config.json at the root of your project. Every key is optional; sensible defaults apply when a key is missing.

Tip: press / or Ctrl K anywhere to jump to a page or run an action.

Environments

Define one block per environment. Values in an environment block override the top-level defaults, so staging can point at a different region without duplicating the whole file.

{
  "region": "eu-west",
  "environments": {
    "staging": { "region": "eu-central", "replicas": 1 },
    "production": { "replicas": 3 }
  }
}

Secrets

Never commit secrets. Reference them as "$env:NAME" and Atlas resolves them at deploy time from the environment of the build runner.

Validation

Run atlas check before deploying. It validates the schema, flags unknown keys and prints a diff of the effective configuration per environment.
