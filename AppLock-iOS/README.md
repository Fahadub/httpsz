# AppLock — قفل التطبيقات لـ iOS

تطبيق SwiftUI لقفل تطبيقات الآيفون برمز (٤ أو ٦ أرقام) أو بنمط سحب (٣×٣)، مع ٥ مميزات تكون عادةً مدفوعة في التطبيقات المشابهة، وكلها هنا مجانية.
التصميم بسيط، يدعم الوضع الداكن، والعربية والإنجليزية (RTL)، ويستخدم أيقونات SF Symbols بدل الإيموجي.

## المميزات

| الأساسية | المميزات المدفوعة عادةً (مجانية هنا) |
|---|---|
| قفل عدد غير محدود من التطبيقات والتصنيفات والمواقع | **Face ID / Touch ID**: فتح فوري بدون كتابة الرمز |
| رمز ٤ أو ٦ أرقام، أو نمط سحب | **صور المتسللين**: صورة بالكاميرا الأمامية بعد محاولات خاطئة |
| قفل AppLock نفسه عند الخروج منه | **خزنة صور خاصة**: تشفير AES-256-GCM والمفتاح في Keychain |
| إيقاف مؤقت متصاعد بعد كل ٥ محاولات خاطئة | **القفل المجدول**: قفل تلقائي في ساعات وأيام تحددها |
| غطاء خصوصية في مبدّل التطبيقات | **إعادة القفل الذكية**: تفتح التطبيق لدقائق (١–٦٠) ثم يُقفل وحده |

## كيف يعمل القفل

Apple لا تسمح لأي تطبيق بقفل تطبيق آخر مباشرة. الطريقة الرسمية الوحيدة هي **Screen Time API**، وهي التي تستخدمها تطبيقات القفل في App Store:

1. تختار التطبيقات من `FamilyActivityPicker`، فيضع النظام عليها شاشة قفل (Shield) بتصميمنا.
2. عند فتح تطبيق مقفل والضغط على **فتح**، يصلك إشعار. تضغط عليه فيفتح AppLock، وتدخل الرمز أو النمط أو Face ID.
3. يُفتح ذلك التطبيق فقط للمدة المحددة، ثم يُقفل تلقائيًا عبر إضافة DeviceActivity حتى لو كان AppLock مغلقًا.

> قيد من Apple: شاشة القفل التي يرسمها النظام لا تقبل إدخال رمز داخلها، لذلك يتم التحقق داخل AppLock.

## هل يعمل على الماك؟

**لا بالنسبة لقفل التطبيقات.** Screen Time API يعمل على iPhone وiPad فقط، ولا يقفل تطبيقات الماك. لذلك عطّلت تشغيله على الماك (`SUPPORTS_MAC_DESIGNED_FOR_IPHONE_IPAD = NO`). الواجهة متجاوبة مع كل أحجام الآيفون (الطولي والعرضي) ومع الآيباد.

## التشغيل

المتطلبات: Mac عليه **Xcode 16** أو أحدث، و**iOS 17** أو أحدث على جهاز حقيقي (Screen Time لا يعمل على المحاكي)، و**حساب Apple Developer مدفوع**، لأن صلاحية Family Controls غير متاحة للحساب المجاني.

1. افتح `AppLock.xcodeproj`.
2. من **Project ▸ AppLock ▸ Build Settings** غيّر `BASE_BUNDLE_ID` من `com.example.applock` إلى معرّف خاص بك، مثل `com.yourname.applock`. كل المعرّفات ومجموعة App Group تُشتق منه تلقائيًا.
3. في **Signing & Capabilities** اختر فريقك (Team) لكل الأهداف الأربعة: `AppLock` و`ShieldConfiguration` و`ShieldAction` و`ActivityMonitor`. تأكد أن **App Groups** مفعّلة على `group.<BASE_BUNDLE_ID>`، واضغط زر التحديث إن ظهرت باللون الأحمر.
4. شغّل على الآيفون (⌘R).

للنشر في App Store: اطلب صلاحية التوزيع لـ Family Controls من
https://developer.apple.com/contact/request/family-controls-distribution
لكل Bundle ID من الأربعة. التطوير والتجربة على جهازك تعمل بدون هذا الطلب.

## هيكل المشروع

```
AppLock/                 التطبيق الرئيسي (SwiftUI)
  App/                   نقطة البداية والحالة العامة
  Security/              الرمز (Keychain + SHA-256 مملّح)، Face ID، كاميرا المتسللين، جلسة القفل
  Storage/               التخزين المشفّر للخزنة وصور المتسللين
  Views/                 القفل، الرمز والنمط، التهيئة، التبويبات الأربعة
  Resources/             الأيقونة، الألوان، الترجمة العربية
Shared/                  كود مشترك مع الإضافات (الإعدادات، تطبيق القفل والجدولة)
ShieldConfiguration/     تصميم شاشة القفل فوق التطبيق المقفل
ShieldAction/            أزرار شاشة القفل (فتح / إغلاق)
ActivityMonitor/         إعادة القفل والجدول في الخلفية
scripts/generate_project.rb   يعيد توليد ملف المشروع: gem install xcodeproj && ruby scripts/generate_project.rb
```

## ملاحظات

- لا يجمع التطبيق أي بيانات، وكل شيء يبقى على الجهاز.
- صور الخزنة مستبعدة من النسخ الاحتياطي، لأن مفتاح التشفير مرتبط بالجهاز. حذف التطبيق يحذفها.
- حد Apple: ٥٠ تطبيقًا كحد أقصى في قائمة القفل الواحدة (يمكن قفل تصنيفات كاملة بدلًا من ذلك).
- كُتب الكود على Linux بدون Xcode، فلم يُبنَ بعد. أول بناء قد يُظهر تحذيرات أو أخطاء بسيطة، فأرسلها لي وأصلحها.
