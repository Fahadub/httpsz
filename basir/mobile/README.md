# بصير — تطبيق أندرويد (APK) وآيفون

نسخة التطبيق الأصلي تغلّف واجهة بصير نفسها عبر [Capacitor](https://capacitorjs.com)، وتضيف ما لا يستطيعه تطبيق الويب:

- **اختصار خفض الصوت 3 مرات** بعد فتح قفل الشاشة: يفتح بصير ويبدأ الاستماع من أي شاشة (أندرويد).
- التعرّف على الكلام والنطق بمحركات الجهاز نفسه.
- الاتصال بخادم بصير المحلي `http://192.168.x.x:7777` مباشرة، دون الحاجة إلى HTTPS.
- إبقاء الشاشة مضاءة أثناء الإرشاد.

الخادم يبقى PHP كما هو: التطبيق يتصل به، والمفتاح يبقى محفوظاً على الخادم.

## أندرويد

### الطريقة الأسهل: GitHub Actions (بدون تثبيت شيء)

مع كل تعديل في مجلد `basir/` يُبنى ملف APK تلقائياً:

**Actions ← Basir Android APK ← آخر تشغيل ← Artifacts ← basir-android-apk**

لتضمين عنوان خادمك داخل التطبيق: **Run workflow**، ثم اكتب العنوان مثل `http://192.168.1.10:7777`. وإن لم تكتبه يطلبه التطبيق مرة واحدة عند أول تشغيل.

### أو على جهازك

المتطلبات: Node 22، و JDK 21، و Android Studio (أو Android SDK).

```bash
cd basir/mobile
npm install
node scripts/build-www.mjs http://192.168.1.10:7777   # عنوان خادمك (اختياري)
npx cap add android
node scripts/patch-android.mjs
npx cap sync android
cd android && ./gradlew assembleDebug
# الملف: android/app/build/outputs/apk/debug/app-debug.apk
```

### تفعيل اختصار خفض الصوت (مرة واحدة، بمساعدة مبصر)

1. ثبّت الـ APK وافتحه مرة، واسمح بالكاميرا والميكروفون.
2. **أندرويد 13 وما بعده:** الإعدادات ← التطبيقات ← بصير ← القائمة (⋮) ← **السماح بالإعدادات المقيّدة**. هذا مطلوب لأن التطبيق ليس من المتجر.
3. الإعدادات ← **تسهيل الاستخدام** ← التطبيقات المثبتة ← **اختصار بصير** ← تشغيل.
4. الآن: افتح قفل الشاشة، ثم اضغط **خفض الصوت 3 مرات بسرعة**. يفتح بصير ويصفّر، فتكلّم.

الخدمة **لا تقرأ محتوى الشاشة**، وتستمع لزر خفض الصوت فقط، ولا تمنع عمله العادي. بعد الاختصار يعيد بصير مستوى الصوت كما كان.

## آيفون (iOS)

يحتاج جهاز ماك عليه Xcode، وحساب Apple (مجاني للتجربة على جوالك، أو مدفوع للنشر).

```bash
cd basir/mobile
npm install
node scripts/build-www.mjs http://192.168.1.10:7777
npx cap add ios
node scripts/patch-ios.mjs
npx cap sync ios
npx cap open ios      # في Xcode: اختر فريقك (Signing) ثم شغّل على الجوال
```

**الاختصار على آيفون:** أبل لا تسمح لأي تطبيق بالتقاط أزرار الصوت. البديل الأقرب:

**الإعدادات ← تسهيلات الاستخدام ← اللمس ← النقر على الخلف ← نقر ثلاثي ← اختصار «فتح التطبيق: بصير»**

بعدها ثلاث نقرات على ظهر الجوال تفتح بصير. ويمكن أيضاً: «يا سيري افتح بصير»، أو زر الإجراءات في آيفون 15 برو وما بعده.

> بدون ماك: تطبيق الويب (PWA) يعمل على آيفون من سفاري عبر «إضافة إلى الشاشة الرئيسية»، بشرط أن يكون رابط الخادم HTTPS. راجع README الرئيسي.

## تغيير عنوان الخادم لاحقاً

داخل التطبيق قل «الإعدادات». أو إذا لم يجد التطبيق الخادم ستُفتح شاشة «عنوان خادم بصير» تلقائياً. يُحفظ العنوان مرة واحدة على الجوال.
