# قفل التطبيقات (iOS)

تطبيق SwiftUI بسيط: رمز سري من 4 أرقام + Face ID، وقائمة تطبيقات تفتحها بعد إدخال الرمز.

## التثبيت بدون حساب مطور مدفوع
1. **بناء IPA**: من تبويب Actions في GitHub شغّل «Build AppLock IPA» ثم نزّل `AppLock-ipa`.
2. **التوقيع والتثبيت** (ويندوز أو ماك): ثبّت [Sideloadly](https://sideloadly.io) + iTunes، وصل الآيفون بالكيبل، اسحب الـIPA وأدخل Apple ID عادي (مجاني) ثم Start.
3. على الآيفون: الإعدادات ← عام ← VPN وإدارة الجهاز ← ثق بحسابك.
4. iOS 16+: الإعدادات ← الخصوصية والأمن ← **وضع المطور** ← تشغيل وإعادة تشغيل.

> الحساب المجاني: التطبيق يعمل **7 أيام** ثم أعد التثبيت (أو استخدم SideStore للتجديد التلقائي).

**بديل بماك**: `brew install xcodegen && xcodegen generate` ثم افتح المشروع في Xcode ← Signing ← اختر Apple ID ← غيّر Bundle ID ← Run على الآيفون.

## القفل الفعلي للتطبيقات
iOS لا يسمح لأي تطبيق بقفل تطبيق آخر مباشرة. الحل عبر الاختصارات:
الاختصارات ← أتمتة ← التطبيق ← WhatsApp ← «عند الفتح» ← تشغيل فوري ← «فتح عناوين URL»: `applock://open?app=WhatsApp`
